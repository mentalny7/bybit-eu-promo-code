## Promo code, referral code, coupon, voucher: what's the difference?

Bybit EU uses several words for things that look similar, and mixing them up is the main reason people think their promo code "didn't work".

| Term | What it is on Bybit EU | When you deal with it |
|---|---|---|
| **Promo code / referral code / invite code** | The code typed in at registration, such as `BYBIT3K` | Once, on the sign-up form |
| **Coupon** | A reward credited to your account, for example a trading or deposit bonus coupon | After you finish a task |
| **Voucher** | Similar to a coupon. Can be used for specific actions within a time limit | After a task or campaign |
| **Rewards Hub** | The page that lists your tasks, coupons and vouchers | Any time after sign-up |
| **Verification code** | A one-time number sent by email or SMS | Login, sign-up, withdrawals |

So: the **Bybit EU promo code BYBIT3K** is entered once. Coupons and vouchers arrive later in the Rewards Hub, and you never type a code to receive them. If someone tells you to "redeem" a Bybit promo code in your existing account, check carefully where that instruction came from.

## How Bybit EU promotions are structured

Understanding the structure helps you get the most out of the Bybit EU promo code. Most new-user campaigns follow the same pattern:

1. **Entry condition:** register with a referral code such as BYBIT3K and pass KYC.
2. **Basic tasks:** low-effort steps with small, guaranteed rewards, for example a first deposit or a first trade.
3. **Milestone tasks:** higher deposit or trading amounts within a time window, with bigger rewards.
4. **Usage conditions:** coupons and vouchers often have to be used within a few days and sometimes only on certain products.
5. **Expiry:** anything unclaimed or unused by the deadline is gone.

The basic tasks are worth doing for almost everyone. Milestone tasks only make sense if they match what you were going to deposit or trade anyway.

## Using your coupons the smart way

Once the Bybit EU promo code has done its job and coupons start appearing, a few habits help you get real value out of them:

- **Check the expiry date the moment a coupon lands.** Some last only a few days.
- **Read what each coupon is for.** A coupon valid for spot trading won't apply to a card purchase, and the other way around.
- **Use coupons on trades you'd make anyway.** Don't trade more than you planned just to use a coupon.
- **Mind the minimums.** Some coupons apply only to trades or deposits above a set size.
- **Keep a simple list** of coupons, values and deadlines in your notes app during the first month.
